# 紧凑胶囊、纸片缩放与章节入口

本轮基线是对话附件 `papertodo-native-visual-source.zip`。没有从远端旧版本开始，也未改动 GitHub 或正式网站。

当前用户的五项新要求优先于 `VISUAL-REVISION.md`、`INTERACTION-REVISION.md` 和更早说明：周末计划现在需要独立胶囊，不再沿用“关联笔记不出胶囊”的旧规则。

## 实现

- 普通胶囊从 128px 缩至 104px。桌面预览从 320px 缩至 248px；触屏预览为 268px。可见主体仍为 30px，触屏命中范围仍为 44px。
- 待办默认约 300×178，笔记约 320×334；矮窗口和手机按空间约束。Markdown 阅读形态不再占满整个工作台。长内容在纸片内滚动。
- 待办、笔记、生成工具和脚本纸均可拖动顶栏移动，也可拖动右下角／右边／下边调整大小。边界按实际工作台计算；文字不缩放；尺寸与位置保留在当前会话。触屏使用较大的右下角抓手。
- 新增侧边周末计划、工具制作、脚本入口。点击分别进入 Markdown、制作、脚本章节；同章再次打开不会重复滚动。悬停只预览，不切换章节；键盘 Left Arrow 和触屏长按打开预览。
- 侧边仅有待办、周末计划、工具制作、脚本四个固定成员，以及至多一个生成工具。队列收起开关移到工作台右上角，不另占胶囊。
- 新工具先成功构造，才替换旧实例并清理旧计时器。取消、输入校验失败和构造失败保留现有工具。预览与展开仍共用一个运行实例。
- 脚本胶囊右侧增加 ▶；点击呈现运行中状态、闪动光标和结果反馈，可重复执行。脚本纸收起归入侧边，不再额外产生漂浮胶囊。没有执行本机 PowerShell。

## 交互修正

正常速度拖拽测试发现了逐次使用整数 `offsetWidth` 造成的尺寸漂移，已改为读取保留亚像素的实际矩形。收起后恢复和取消手势均验证真实尺寸，不依赖静态截图。

页面保留上一轮的简短文案、空白制作输入、原生风格勾选框和主题。没有重新加入长提示词或实现规则说明。当前原生外观参考沿用上一轮已记录的正式程序源码；本轮新增的五入口组织、缩放边界及脚本反馈是实验网站交互，并非 Windows 实机录制。

## 验证与边界

详见 `evidence/VALIDATION.json` 和各测试报告。动效通过正常速度鼠标、键盘、滚轮操作及逐帧 DOM 矩形记录检查，并保留浏览器录屏。触屏由 Chromium 输入模拟，不声称实体手机实测。

本环境真实 HTTP 浏览器首次导航返回 `ERR_BLOCKED_BY_ADMINISTRATOR`。因此 DOM 交互与录屏明确使用 `PAPER_DEMO_IN_MEMORY=1`；它们不能代替 HTTP、模块获取和首页 CSP 验收。离线预览保留自己的 CSP 单独验证；模块链接和 HTTP 文件字节检查也单独报告。没有调整浏览器管理策略。
