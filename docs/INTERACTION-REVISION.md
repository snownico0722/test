## 交互变化

| 要求 | 本次实现 |
| --- | --- |
| 工作台形态连续过渡 | 保留同一个工作台与真实纸片节点。共享动效模块从当前呈现的矩形接续，动画可以被新目标中断；不复制截图、不同时维护第二套画布。纸片以真实宽高变化收起和展开，正文不被整体缩放。 |
| 预览与真实产品含义对应 | 胶囊原位变宽、变高，后续队列让位；向下切换尽量保持目标位置，空间不足时向上展开，退出后回到紧凑队列。正文随形态淡入／淡出。勾选框只勾选、关联按钮只打开原笔记、其余预览正文点击恢复完整纸片。 |
| 普通胶囊常驻 | 待办与已生成工具均保留侧边入口，与纸片是否展开分离。主胶囊仍可显式隐藏／显示队列。关联笔记不注册独立胶囊，通过原待办的关联入口打开。 |
| 顶栏拖动 | 恢复鼠标和触屏拖动；按钮、链接和输入控件不触发拖动。限制在工作台内部，拖动后折叠／恢复仍返回保存的位置。焦点位于顶栏时，方向键移动，Shift 加大步长，Escape 取消当前拖动。 |
| 新工具成功后归边 | 成功后自动退出制作形态，工具沿过渡进入侧边唯一位置。候选工具先构造成功，才提交替换并释放旧运行实例；取消、未知需求与构造失败保留旧工具。预览与完整工具纸使用同一个运行实例。 |
| 图标与名称常态显示 | 胶囊和纸片顶栏共用同一名称入口，语言切换、模板替换同步更新。不需要悬停才能知道胶囊属于哪张纸。 |

继续保留双语、三档 Markdown 对照、脚本演示、三个本地模板、工具必要操作、源码及 HTML 导出。移除了旧的制作完成后另点一次“放回桌面”路径。脚本与制作仍不调用 PowerShell、Codex、API 或安装原生插件。

**网页适配，不是原生移植：** 使用 DOM 和 Web Animations API，而非 WPF／DirectComposition。网页队列只有两个固定成员，额外约束所有操作在当前工作台内可达；这与原生长队列允许成员溢出工作区的策略不同。动画时长、比例、触屏点击预览和键盘入口为网站设计。关联笔记无独立胶囊、生成后单槽替换是本轮明确要求，不宣称它们是所有 PaperTodo 场景的全局规则。

没有运行 Windows 原生程序，也没有当前版本原生实机录屏；不能称为逐像素复刻、原生动效实测或相同帧率。交付截图和视频均来自实际网页浏览器。

## 文件与重现

运行：`python -m http.server 4173 --directory website`。中文 `http://localhost:4173/?lang=zh`，英文 `?lang=en`。可直接用浏览器打开根目录 `preview.html`。

主要入口：`website/assets/playground.mjs`；状态与队列：`story-core.mjs`；可中断动效：`motion.mjs`；样式：`playground.css`。`plugin-core.mjs` 保持附件版本不变。

`tests/browser_smoke.py` 默认只走真实 HTTP；`--group motion --record` 运行正常速度操作并录屏。默认测试批次使用独立子进程，`--case` 可缩小到指定案例。受限环境可显式启用 DOM 模式，但不得把其结果当成 HTTP 通过。

源码包是一套完整可运行文件，不是依赖 `011bcee` 的旧补丁。旧交付的应用脚本已移除，避免误用旧 Git 基线。`verify-package.py` 只校验哈希，不修改仓库。历史需求与说明保留在 `docs/`，不再代表当前交互规则。
