# 第三轮布局与导航更新

基于 `papertodo-compact-v2-source.zip`，保留上一轮关联笔记、预设工具、固定胶囊和 Markdown 关闭模式的行为。

1. 五个章节的“继续了解”在说明栏中横向居中，箭头紧贴文字下方，每章指向下一章，工具章指向更多功能。
2. 双栏桌面使用浏览器原生纵向滚动吸附，章节位置与导航栏留白对齐。纸片内部滚动独立，不连带滚动整页。未拦截滚轮事件；减少动态效果设置仍生效。窄屏沿用标签、上一章／下一章和继续了解切换。
3. 脚本章节左侧只保留一个按钮：运行脚本 → 回到纸片 → 运行脚本。运行中也可立即返回，计时任务随之取消。纸片和胶囊的运行入口保留；powershell 结果内仍只有关闭和回到纸片。
4. 深色模式改为两挡 range 滑块，可拖动，也可用 Home/End 或方向键切换，向辅助技术提供浅色／深色状态。
5. 删除演示区外层顶栏，演示画布从上边缘开始。网站顶栏以及实际纸片的拖动顶栏保留。
6. 删除手册、源码、GitHub、下载链接文字旁的 ↗，保留原链接地址和下载功能。
7. 宽度低于 980px 时，“章节编号 - 标题”合为一行，隐藏章节说明段落，紧接操作按钮。“收起／预览／展开”保持并列。中等宽度顶栏 54px、画布外框 580px；540px 及以下顶栏 48px、演示区 660px。手机的待办纸片保持 200px 高，三项待办可见，笔记内容在纸片内部滚动。
