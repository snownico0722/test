- 待办移除横向分隔线，使用圆角悬停底色。复选框改为真实 input 上的自定义描边和勾号；支持键盘、焦点和高对比度模式。
- 预览改为内容区内的“标题＋数量”，删除整条底部打开栏。标题仍可打开纸片；收回入口放在边侧。原有勾选、关联、队列切换与工具状态保持。
- 删去重复步骤、旁注、状态保留解释、制作后的实现规则和重复标语。缩短六项特性和五项 FAQ；待办、笔记改用正常生活内容示例。
- 制作输入默认留空，示例按钮只填短语，不预写长提示词。制作区保留一句“本地预设演示，未实时调用 Codex”；导出边界留在折叠的导出区域。
- 工具内部删除重复口号和介绍，不改变计时、暂停、勾选、添加条目及导出。

## 验证
