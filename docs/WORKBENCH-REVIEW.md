| 项目 | 现在的行为 |
| --- | --- |

| Markdown | 关闭、基础、完全渲染三档，网站控制放在讲解侧。完全渲染中的任务框可勾选；切语言、回看章节不丢状态。 |
| 脚本 | 预设 `!p` 笔记 → 闪电胶囊 → 浏览器结果 → 返回原脚本。没有 PowerShell 执行。 |
| 插件制作 | 同一舞台退开原纸片，展示输入、三步本地拼装、可操作结果。完成后原处恢复桌面，不增加画布、不跳回顶部。 |
| 唯一插件 | 同一个已挂载组件从制作区移回原桌面、再移到胶囊预览。重复生成成功时才释放旧实例；取消不会销毁旧工具。 |
| 精简说明 | 制作区集中一处说明“本地预设、未实时调用 Codex、非桌面插件包”。源码与导出折叠收纳。 |
| 页面完整性 | 保留两列六项特性、五项 FAQ、下载与页脚。没有把主要功能移到归档页面。 |
| 窄屏与短窗口 | 宽度决定桌面／窄屏布局，不再用高度隐藏工作台。手机只显示当前讲解，同一工作台纵向排列。 |
