# 第四轮修订记录

基于第三版源码包，继续使用同一套工作台与纸片实例。

## 本轮改动

1. **吸附范围**：前五个演示章节保留原生滚动吸附。离开第五章后关闭吸附，后续功能介绍、FAQ 和下载区域自由滚动；返回演示区恢复吸附。第五章外保留一个退出候选点，让浏览器能离开最后一个强制吸附点，随后随滚动立即停用吸附。
2. **窄屏引导**：小于 980px 时隐藏“继续了解”和“体验纸片演示”，保留章节标签和上一章／下一章。
3. **窄屏标题**：用浅色编号块与 14–18px 标题形成层次，统一字体与字重，弱化后半句。窄屏不重复显示长章节前缀，也不靠省略号硬截断标题；空间特别小时允许自然换行。
4. **Markdown 大小**：进入 Markdown 页时，原笔记默认放大到不超过 414 × 440px；其他页使用原来的紧凑尺寸。用户拖动或调整大小，包括方向键操作后，改用持久的用户尺寸和位置，章节切换不再覆盖。Escape 取消拖动不会接管自动布局。小窗口只限制实际可呈现范围，不丢失偏好尺寸。
5. **插件系统命名**：第五章、导航、章节标签和页面标题同步改名，中英文均更新。
6. **制作时显示隔离**：原问题是制作结束将章节视图切回普通桌面，恢复了原本未收起的待办和笔记。新增插件展示状态，制作中隐藏其他纸片，完成后只打开刚生成的插件。成功替换仍只有一个实例、一个侧边位置；主动点击返回或打开其他纸片时按明确操作执行。
7. **单位换算插件**：完全替代第三个待办清单预设。支持米／英尺、摄氏度／华氏度、千克／磅，输入即换算，可交换方向。切换换算类别、语言、纸片和胶囊预览保留插件状态。空输入和无效数字不显示 NaN 或 Infinity。插件制作面板仍只有预设选择。
