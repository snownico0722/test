07 / FAQ

Before the first paper.

Which Windows version do I need?

Windows 10 / 11 x64. A separate best-effort build is available for Windows 7 SP1 x64; check the release notes.

How do I back up or move my papers?

Close PaperTodo and copy the entire app folder, including notes, images and plugin data.

Why might Windows SmartScreen show a warning?

Windows may flag unfamiliar or unsigned apps. Download from the official GitHub Releases and check the source before running.

Can I change the colors and font?

Four palettes, light and dark themes, and system or custom fonts.

Are there global shortcuts and launch arguments?

Yes. Set global shortcuts in the app, or use launch arguments for common actions. See the user guide for details.
