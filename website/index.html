07 / A FEW GOOD QUESTIONS

Before the first paper.

Which Windows version do I need?

Use the standard x64 build on Windows 10 or 11. The separate Windows 7 SP1 x64 build is best-effort compatibility. Check the notes on the release you download; the self-contained build includes its runtime.

How do I back up or move my papers?

Exit PaperTodo, then copy the whole writable application folder. Keep data.json, note-assets.lmdb, plugin data, and the other files together. Do not move only the executable.

Why might Windows SmartScreen show a warning?

An unfamiliar or unsigned build can trigger a warning. Download from the project’s GitHub Releases and verify the source before running it. Do not disable Windows protection to use a demo.

Can I change the colors and font?

Yes. Warm Paper, Ink, Forest, and Rosy each support light and dark appearance, or following the system. Choose the language default, Microsoft YaHei, DengXian, or a custom papertodo.ttf / papertodo.otf file in the application folder.

Are there global shortcuts and launch arguments?

Yes. Bind the common actions in settings, or use --show, --hide, --toggle, --new-todo, and --new-note. Desktop shortcuts belong to the app; this web demo does not intercept them.
